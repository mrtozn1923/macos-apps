# macOS Apps

Small, native, fully local macOS apps I build as I need them.
Each app lives in its own folder and builds independently.

| App | Description | Source |
|---|---|---|
| [TıkKare](https://mrtozn1923.github.io/macos-apps/tikkare/) | Lightshot-style screenshot tool: area / window / full screen / scrolling capture, annotation tools, OCR. Fully local. | [`TikKare/`](TikKare/) |
| [NabızTut](https://mrtozn1923.github.io/macos-apps/nabiztut/) | Desktop uptime monitor: checks websites, APIs and servers (HTTP, ping, TCP) on your schedule, with response-time charts and down alerts. Fully local. | [`NabizTut/`](NabizTut/) |

## Requirements

- Apple silicon Mac
- To build from source: Xcode (or the Xcode Command Line Tools) with Swift 5.10+
