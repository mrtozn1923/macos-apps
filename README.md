# macOS Apps

Small, native, fully local macOS apps I build as I need them.
Each app lives in its own folder and builds independently.

| App | Description |
|---|---|
| [TıkKare](TikKare/) | Lightshot-style screenshot tool: area / window / full screen / scrolling capture, annotation tools, OCR. Fully local. |

## Requirements

- Apple silicon Mac
- To build from source: Xcode (or the Xcode Command Line Tools) with Swift 5.10+
