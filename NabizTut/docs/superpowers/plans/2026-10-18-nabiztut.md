# NabızTut Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Native macOS desktop-panel uptime monitor (HTTP/ping/TCP) with history charts, notifications and local SQLite storage.

**Architecture:** SwiftPM executable assembled into a signed `.app` by `scripts/build.sh`. AppKit hosts a desktop-level `NSPanel` and the menu bar item; SwiftUI renders panel, detail and settings content. A scheduler drives checkers; results flow into SQLite and a pure status engine.

**Tech Stack:** Swift 6.4 toolchain (Swift 5 mode), AppKit, SwiftUI, Swift Charts, URLSession, Network, UserNotifications, ServiceManagement, Security (Keychain), system libsqlite3.

**Spec:** `NabizTut/docs/superpowers/specs/2026-10-18-nabiztut-design.md`

## Global Constraints

- macOS 14+, arm64, `LSUIElement`, bundle id `com.mertozen.nabiztut`, display name NabızTut, ASCII name `NabizTut`.
- No third-party dependencies; no paths outside `NabizTut/`.
- Intervals: 1, 2, 5, 10, 15, 30, 60 min (min 1, default 5); timeout default 10 s (1–60 s).
- Down after 2 consecutive failures; confirmation check 30 s after the first failure.
- Raw checks 7 days, hourly rollups 30 days, incidents 30 days.
- UI strings: English keys + `tr.lproj`; code/comments English.
- No unit tests (user preference). Verification: `swift build` clean + local test server + running the app.

### Task 2: Model + config
**Files:** `Model/{Monitor,CheckResult,MonitorStatus,Incident}.swift`, `Config/{MonitorStore,SecretStore}.swift`
**Produces:**
- `struct Monitor: Codable, Identifiable, Hashable` — `id: UUID, name, kind: MonitorKind (.http/.ping/.tcp), url: String, host: String, port: Int, intervalMinutes: Int, timeoutSeconds: Int, method: HTTPMethod, headers: [HeaderField], body: String, expectedStatus: String, keyword: String, keywordMode: KeywordMode (.contains/.notContains), followRedirects: Bool, sslWarnDays: Int, notify: Bool, paused: Bool`; `static let intervals = [1,2,5,10,15,30,60]`; `var target: String`.
- `struct HeaderField: Codable, Hashable, Identifiable { id, name, value, secret }`.
- `struct CheckResult { monitorID, date, ok, statusCode: Int?, latencyMs: Int?, error: String?, certExpiry: Date? }`.
- `enum MonitorState { up, down, warning, paused, unknown }`; `struct MonitorStatus { state, lastResult, since, reason }`.
- `@MainActor final class MonitorStore` — `monitors`, `load()`, `save()`, `upsert(_:)`, `delete(_:)`; secrets via `SecretStore.set/get/delete(monitorID:header:)`.

### Task 3: SQLite + history
**Files:** `Storage/{Database,HistoryRepository}.swift`
**Produces:** `final class HistoryRepository` (actor-isolated via serial queue) — `insert(_ result: CheckResult)`, `samples(monitorID:since:) -> [Sample]`, `hourly(monitorID:since:) -> [HourlySample]`, `uptime(monitorID:since:) -> Double?`, `medianLatency(monitorID:since:) -> Int?`, `openIncident(monitorID:start:reason:)`, `closeIncident(monitorID:end:)`, `incidents(monitorID:since:) -> [Incident]`, `sslWarned(monitorID:expiry:) -> Bool`, `markSSLWarned(...)`, `maintain(now:)` (rollup >7 d into hourly, delete raw >7 d, hourly/incidents >30 d), `deleteAll(monitorID:)`. Corrupt DB → rename aside and recreate.

### Task 4: Checkers
**Files:** `Checks/{Checker,HTTPChecker,PingChecker,TCPChecker,CertificateInspector,StatusCodeRule}.swift`
**Produces:** `protocol Checker { func check(_ monitor: Monitor) async -> CheckResult }`; `enum Checkers { static func check(_:) async -> CheckResult }`. HTTP: ephemeral session, UA, HEAD optimisation with 405/501 fallback, redirect policy, 1 MB keyword read, cert expiry via `URLSessionDelegate` trust challenge. Ping: ICMP `SOCK_DGRAM` echo. TCP: `NWConnection` with timeout.
