# TıkKare Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Native Apple-silicon menu bar screenshot app (area/window/full/scrolling/OCR) with on-screen + editor-window annotation, copy and save — fully local.

**Architecture:** Swift Package executable assembled into a signed `.app` by a script. AppKit for overlay/canvas/editor, SwiftUI for Settings. A single `AnnotationRenderer` draws both on screen and on export.

**Tech Stack:** Swift 6.4, AppKit, SwiftUI, ScreenCaptureKit, Vision, CoreImage, Carbon hotkeys, ServiceManagement.

**Spec:** `docs/superpowers/specs/2026-10-10-tikkare-design.md`

## Global Constraints

- Minimum macOS 14.0; arm64 build.
- Bundle id `com.mertozen.tikkare`, `LSUIElement = true`.
- Sign with the local "Apple Development" certificate when available, otherwise ad-hoc.
- UI strings Turkish; code/comments/identifiers English.
- No unit tests (user preference). Verification = `swift build` clean + manual run.
- No network access of any kind.
- Default hotkeys `⌥⇧1` area, `⌥⇧2` full, `⌥⇧3` scrolling, `⌥⇧4` OCR.
- Save folder default `~/Pictures/Screenshots`, filename `Screenshot yyyy-MM-dd 'at' HH.mm.ss.png`.

### Task 3: Screen capture + permissions

**Files:** `Capture/ScreenCapturer.swift`, `Capture/Permissions.swift`, `Capture/WindowLocator.swift`

**Produces:**
- `struct FrozenScreen { screen: NSScreen; image: CGImage; scale: CGFloat }`
- `ScreenCapturer.captureAllScreens() async throws -> [FrozenScreen]`
- `ScreenCapturer.captureWindow(id: CGWindowID) async throws -> CGImage`
- `ScreenCapturer.captureRect(_ rect: CGRect /*global AppKit coords*/, on screen: NSScreen, excludingOwnApp: Bool) async throws -> CGImage`

### Task 4: Annotation model + renderer

**Files:** `Annotation/Annotation.swift`, `Annotation/AnnotationDocument.swift`, `Annotation/AnnotationRenderer.swift`, `Annotation/Pixelator.swift`

**Produces:**
- `enum Tool { arrow, rectangle, ellipse, pen, line, text, highlighter, blur, number }`
- `struct Annotation { id; kind: Kind; color: NSColor; width: CGFloat }`, `Kind` cases: `.arrow(CGPoint,CGPoint)`, `.rectangle(CGRect)`, `.ellipse(CGRect)`, `.pen([CGPoint])`, `.line(CGPoint,CGPoint)`, `.text(String, CGPoint, fontSize)`, `.highlighter([CGPoint])`, `.blur(CGRect)`, `.number(Int, CGPoint)`. Coordinates in image points (bottom-left origin).
- `AnnotationDocument` (`baseImage: CGImage`, `pointSize: CGSize`, `annotations`, `add/replaceLast/remove`, `undo/redo`, `canUndo/canRedo`, `nextNumber`, `onChange`).
- `AnnotationRenderer.draw(_ doc:, in ctx: CGContext, pixelatedBase: CGImage?)`; `AnnotationRenderer.flatten(_ doc:) -> CGImage` at full pixel size.
