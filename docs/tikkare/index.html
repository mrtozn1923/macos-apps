TıkKare

Capture, annotate, done.

A Lightshot-style screenshot tool that lives in your menu bar. Turkish for “click, frame”: one click, one shot.

Download for Mac View source

v1.0.0 · macOS 14 or later · Apple silicon · English & Turkish

Everything you need, nothing you don't

📸

Every kind of capture

Select an area, click a window, grab the full screen, or stitch a long scrolling page.

✏️

Annotate on screen

The toolbar appears right next to your selection. Arrows, boxes, ellipses, pen, lines, text and highlighter.

🔒

Blur secrets

Pixelate API keys, emails or anything sensitive before you share.

🔢

Numbered steps

Drop 1, 2, 3 badges to explain a flow. Numbers increase automatically.

🔤

Copy text (OCR)

Select any area and its text lands on your clipboard. Error dialogs, videos, images.

🪟

Editor window

Need more room? Open the capture in a resizable editor with zoom.

⚡️

One-key output

Copy to the clipboard or save a Retina PNG with a single keystroke.

🛡️

100% local

No cloud, no account, no tracking. Your screenshots never leave your Mac.

Install

  1. Download TikKare.zip, open it and move TikKare.app to your Applications folder.
  2. TıkKare isn't notarized by Apple yet, so macOS blocks the first launch. Try to open it once, then go to System Settings › Privacy & Security and click Open Anyway.
  3. On the first capture, allow Screen & System Audio Recording and restart TıkKare.

Build from source

Requires Xcode or the Command Line Tools.

git clone https://github.com/mrtozn1923/macos-apps.git
cd macos-apps/TikKare
./scripts/build.sh --install

The app's interface follows your macOS language: Turkish or English.
